Expense Tracker

A simple expense tracker built with React and Vite.

Features

    * Add income and expenses
    * Delete expenses
    * Track balance
    * View total income and expenses
    * Add expenses by category
    * Save data in localStorage

Built With

    * React
    * Vite
    * JavaScript
    * CSS

Run Locally

    npm install
    npm run dev
